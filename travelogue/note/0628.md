# 0628 (六)

- 天氣 : 陰

一早起來就拉著友人 N 出門了。

我們原定的 plan 原本是這樣的 : 先去奧斯陸新國家美術館 -> 阿克胡斯堡 -> 奧斯陸街頭逛逛。

結果友人 N 帶錯了路，我們先花半小時逛了阿克胡斯堡，但裡面的漂亮程度超出預期。

經過的路上還有可愛的馬，我們在那邊拍了很多照片。

--

奧斯陸新國家美術館是一個相當大的場館，總共 80 多個展區，B1 可以先放個人包包。

一樓的場館大多是文物等等，在最開始有一個特別展覽室，裡面展出的是北歐的一些生態與歷史、還有當地美食等等。

也有一些植被的相關介紹。

但因為我英文不太好，很多東西基本上都是看個大概沒有懂。

大致上就是挪威的魚湯以及一些菇類、海菜等是他們的傳統食物。

羊毛也是他們的一些主要產品。

拐進第一個展廳後我被他們豐富的館藏嚇到了，非常豐富的歷史文物。

包括瓷器、鐵器、陶器等多不勝數。

同時期還會有一些家具的展出，並且寫出這時候是因為正在與哪個國家貿易所以有哪方面的影響。

還有絲綢、地毯等一類物品，我甚至還看到了唐三彩(應該)。

基本上光在一樓我和友人 N 就待了近三個半小時，沒有吃午餐就趕緊往二樓走(因為這時我們才逛了一半的館藏)

一樓如果著重在歷史文化方面，二樓的館藏則是著重在美術部分。

從早期的油畫、到現在的美術、裝置藝術等，皆有展出。同時也會配合文字敘述這位挪威家是受到何種影響所創作，其中也有幾幅大型油畫是我自己相當喜歡的。

館藏有部分是版畫，有部分是真跡。

並且某些個別畫家還有自己的互動展廳，可以說是非常用心了。

往後走、則開始出現一些近代美術。但因為我本人是更喜歡古典藝術的人，這一部分有時遇到比較新興的藝術風格會不太舒服(主要是不喜歡恐怖，但不討厭反而很佩服)。

最令我印象深刻是有一個是展出開始像小時候那樣展現自己的主題。作者將一個投影燈放在地上，播放自己的臉，然後將沙發倒扣，在上面鋪上毯子，然後播放他用非常呆板的方式講話的聲音。

我覺得非常有藝術的感覺，雖然當下看會覺得毛骨悚然，還以為有小孩子跌倒甚麼的，轉頭一看是一張大人的臉。

二樓同時也有展出一些順應時代變遷時，此時所設計出的家具。

意外看到以前高中科技課老師叫我們用 3D 建模的方式考試的題目外星人榨汁機，挺有趣的。

美術館 6.關門，我們 10:30 入場，5:30 才逛完，逛了 7 個小時，不愧是我們。

--

出來後看著太陽與峽灣舒服，跟友人 N 去 joker 買了 pizza 跟飲料。

不得不說，挪威人真的很愛吃 pizza。

在奧斯陸，你到處都會看到 pizza 店，連便利商店都可以買到 pizza (重點是還打折，一個 39 兩個 59)

在這邊做了兩個小時，欣賞港口熱鬧的景象，以及蔚藍的天空與水面。

很神奇的是，在奧斯陸港灣你完全聞不到海水或者湖水的味道，空氣是香的。另一方面你又看的到有人會穿著比基尼在路上行走、完全一副在海邊的穿著。

到處都是海鳥，鴿子的比例不高。

有時候我會有一點錯亂，但是 oslo 真的是一個走起來很舒服的城市。

--

途中我們有經過 pride(其實昨晚我們就在擔心 oslo 會不會因為這個 pride 造成交通癱瘓，結果沒有)

舞台的人唱歌挺好聽的。

因為家家戶戶都掛著彩虹旗，所以我們有在思考這是不是同志遊行，不過這邊僅是我們的猜測。因為在這之前，友人 C 在出國前告訴我我們可能是撞上了奧斯陸搖滾音樂節。

結果好像都不是。

但反正我不知道，我只知道他讓房間價格貴了兩倍。

--

晚上我們又回到了阿克胡斯堡將剩下的行程走完。

阿克胡斯堡原本是挪威的戰略中心，現在則是戰略古蹟，不過部分還在使用。

對於戰略中心來說，我覺得裡面有點過於漂亮了。或者說比較像是中古世紀的莊園城堡，而不是作為軍事使用。

裡面還有一些砲台。

而因為漂亮，一路上我跟友人 N 就開始漫無目的地行走，還有晃去他們的音樂中心、聚會所等等，路上還經過已經是古蹟的銀行等，還有有噴水池的小公園。

我跟友人 N 逛的步調很慢，基本上都是逛一下停一下、拍一下再逛一下再停一下。

享受整個城市的氛圍。

--

晚上在超市買了 3 個蘋果還有牛奶，值得一提的是這邊在牛奶的選擇是真的非常的多，非常多不同濃度的版本，不向台灣只分高低脂牛奶。

本來提議跟友人 N 再回去歌劇院欣賞 golden hour。

結果因為太陽一直不下山，然後考量到明天還要去趕小飛機。

"我覺得我們在房間把東西吃一吃就好"我說。

"我沒意見"，友人 N 說。
